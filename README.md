# 📝 To-Do List App

Live Demo 👉 **https://piyushraj45.github.io/todo-list/**

A simple and responsive To-Do List app made using HTML, CSS & JavaScript.

## Features
- Add new tasks
- Delete tasks
- Mark as completed
- Local Storage support
- Responsive Design

## Tech Stack
- HTML5
- CSS3
- JavaScript

## How to Use
1. Type your task
2. Press Enter or click Add
3. Click on task to mark complete / delete
